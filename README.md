# About

Hey there! I'm Jill Fiore, also known online as Lumaeris. Atomic Linux user, tinkerer, Russian translator, aspiring EDM musician and *not yet realized* Pythonista.

My GitHub account mainly exists for contributing to other projects, reporting bugs or hosting my own repositories if there's a need to perform a huge task, such as build an operating system and distribute it as a container. Nowadays I tend to use [Codeberg](https://codeberg.org) and I plan to host my future projects due to concerns related to Microsoft (and by extent GitHub), their collection of data for AI training without consent and continuous failures of GitHub Actions every now and then.

Be sure to check out [my website](https://lumaeris.com) if you want to know me a bit more.

## Projects

- [Zirconium](https://github.com/zirconium-dev) - Atomic Linux system with pre-configured [Niri](https://github.com/niri-wm) and [DankMaterialShell](https://danklinux.com) enrironment based on Fedora Linux, with experimental one being based on Freedesktop SDK. Co-maintainer of Fedora variant.
- [Homebrew Arch repo](https://github.com/Lumaeris/homebrew-arch) - [Homebrew](https://brew.sh) and [brew-proxy](https://codeberg.org/HastD/brew-proxy) packaged for [Arch Linux Bootc](https://github.com/bootcrew/mono) images and distributed as GitHub releases. Semi-automated, Renovate checks for updates for me.
- [Bazzite LDX Nvidia](https://github.com/Lumaeris/bazzite-ldx-nvidia) - A custom [Bazzite](https://bazzite.gg) image with development tools mimicing an official [Bazzite DX](https://dev.bazzite.gg) variant for those who still uses an older NVIDIA GPU (earlier than 16xx or RTX). It was created during the time when I only knew how to work with [BlueBuild](https://blue-build.org) which is still being used in this repo.
- [Stargaze (archived)](https://github.com/Lumaeris/stargaze) - Atomic Linux system based on Arch Linux with Niri and DankMaterialShell meant to be used with systemd-homed. It has been archived due to some issues of both homed and experimental composefs backend of bootc.
